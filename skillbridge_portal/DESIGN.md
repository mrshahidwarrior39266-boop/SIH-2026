## Brand & Style
The design system bridges the rigorous world of academic administration with dynamic corporate talent discovery. It balances institutional authority with the fluid efficiency expected of elite B2B SaaS workflows. The interface must inspire credibility among university deans, confidence within corporate talent scouts, and clarity for students navigating their career trajectories.

The visual style blends **Corporate Modern** with subtle **Glassmorphic Precision**:
- **Structured Architectural Base:** Influenced by Linear and Notion, utilizing crisp borders, information-dense utility bars, and logical grid alignment.
- **Atmospheric Clarity:** Frosted header ribbons, soft layered drop shadows, and subtle internal glow borders deliver a tactile, modern SaaS feel without sacrificing legibility or high-throughput utility.
- **Persona-Centric Micro-Accents:** Specific semantic colors tie institutional nodes (universities, corporate hiring partners, student profiles, and faculty evaluators) into a single cohesive ecosystem.

## Typography
Typographic hierarchy prioritizes tabular readability and instant scanning. `Inter` serves as the primary system-grade workhorse due to its balanced x-height and native OpenType tabular figures (`tnum`), critical for match percentages, test scores, and analytics.

- **Headings:** Use tight negative letter-spacing (`-0.025em` to `-0.01em`) to create an authoritative, editorial finish.
- **Numbers & Metrics:** Use tabular numeral formatting (`font-feature-settings: 'tnum' 1, 'cv05' 1`) across all metric cards, analytics graphs, and leaderboard tables.
- **Technical & Skill Badges:** Utilize `data-mono` (`JetBrains Mono`) for skill identifiers, assessment codes, API sync indicators, and confidence ratings.

## Layout & Spacing
The layout employs an 8-point base grid paired with a 12-column responsive fluid grid inside a 1440px max-width container.

- **Breakpoints:**
  - Mobile: `< 640px` (4-column layout, stacked cards, full-width bottom sheets for filtering)
  - Tablet: `640px - 1024px` (8-column layout, collapsible navigation drawer, multi-column cards)
  - Desktop: `> 1024px` (12-column layout, persistent 260px sidebar navigation, multi-pane drill-down panels)
- **Hierarchy Rhythm:**
  - Dense analytical rows and data grids use `space-xs` (8px) and `space-sm` (12px) padding.
  - Interactive cards use `space-lg` (24px) internal padding.
  - High-level dashboard panels utilize `space-xl` (32px) margins between sections.

## Elevation & Depth
Elevation in this design system uses soft, multi-tier ambient shadows paired with subtle perimeter rings rather than aggressive dark borders.

- **Surface Base (Level 0):** Background canvas (`#F8FAFC`). No shadow.
- **Card Rest (Level 1):** Flat `#FFFFFF` with a 1px solid border in `#E2E8F0` and an ambient shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.02)`.
- **Interactive Hover (Level 2):** Elevated card state. Translates `-1px` on the Y-axis with shadow: `0 10px 15px -3px rgba(15, 23, 42, 0.06), 0 4px 6px -4px rgba(15, 23, 42, 0.03)` with border shifting to `#CBD5E1`.
- **Flyouts & Dropdowns (Level 3):** Popovers, dropdown menus, and date pickers use `0 20px 25px -5px rgba(15, 23, 42, 0.08), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`.
- **Modals & Drawers (Level 4):** Dialog windows feature an overlay with `backdrop-filter: blur(8px)` and background `rgba(15, 23, 42, 0.45)`, paired with `0 25px 50px -12px rgba(15, 23, 42, 0.18)`.
- **Frosted Topbar:** Sticky navigation headers use background `rgba(255, 255, 255, 0.85)` with `backdrop-filter: blur(12px)` and a bottom border `1px solid rgba(226, 232, 240, 0.8)`.

## Shapes
The design uses refined, modern rounded corners that avoid both boxy enterprise aesthetics and playful, over-rounded shapes.

- **Base Radius (8px / `0.5rem`):** Applied to form controls, compact skill chips, tabular badges, and inner nested components.
- **Large Radius (12px / `0.75rem`):** Default for standard dashboard cards, dialog headers, content blocks, and action modals.
- **Extra Large Radius (16px / `1rem`):** Used on primary feature containers, hero banners, and persistent overview cards.
- **Full Radius (9999px / Pill):** Reserved exclusively for status indicators, verification tags, metric pills, and user avatar initials.

## Components

### Buttons
- **Primary:** Solid `#4F46E5`, text `#FFFFFF`, rounded 8px (`0.5rem`). Font weight 600. Subtle shadow: `0 1px 2px rgba(79, 70, 229, 0.2)`. On hover: `#4338CA`. Active: `#3730A3`.
- **Secondary / Soft:** Surface `#EEF2FF`, text `#4338CA`. Border: `1px solid rgba(79, 70, 229, 0.15)`. Hover: `#E0E7FF`.
- **Outline / Neutral:** Surface `#FFFFFF`, text `#334155`, border `1px solid #E2E8F0`. Hover: `#F8FAFC` and border `#CBD5E1`.
- **Danger:** Surface `#FFF1F2`, text `#E11D48`, border `1px solid #FFE4E6`. Hover: `#F43F5E` with text `#FFFFFF`.

### Badges & Chips
- **Skill Chip:** Neutral surface `#F1F5F9`, text `#334155`, font-size 12px, font-weight 500, padding `4px 10px`, border radius 6px. Includes an optional verified dot (`#10B981`) or gap indicator (`#F43F5E`).
- **Match Score Pill:** Pill-shaped badge (`rounded-full`). Background `#F0FDFA`, text `#0D9488`, border `1px solid #CCFBF1`. Font family `JetBrains Mono`, weight 600.
- **Entity Identification Tag:** Subtle uppercase styling (`label-sm`), letter-spacing `0.04em`. 
  - University: `#E0F2FE` text `#0369A1`
  - Industry: `#ECFDF5` text `#047857`
  - Faculty: `#F5F3FF` text `#6D28D9`

### Form Controls
- **Input Fields & Selects:** Height 40px (compact 36px for dense tables). Border `1px solid #CBD5E1`, surface `#FFFFFF`, text `#0F172A`, placeholder `#94A3B8`, border-radius 8px. Internal padding `0 12px`. Focus state: border `#4F46E5`, ring `3px solid rgba(79, 70, 229, 0.15)`.
- **Checkboxes & Radios:** Size 16px. Border `#CBD5E1`, rounded 4px (checkbox) or circular (radio). Checked state: fill `#4F46E5`, white glyph.

### Cards & Data Containers
- **Dashboard Metric Card:** White surface, border `1px solid #E2E8F0`, rounded 12px, padding 20px. Header contains small muted uppercase title (`#64748B`), large stat value (32px, tabular), and an inline trend pill.
- **Applicant & Match List Item:** Horizontal row component with border-bottom `1px solid #F1F5F9`, hover background `#F8FAFC`. Structured left-to-right: Entity Identity Avatar -> Skill Stack Chips -> Match Percentage Progress Bar -> Action Menu.

### Domain-Specific Components
- **Curriculum Gap Radar Card:** Container featuring dual radial or bar comparisons showing required industry competencies vs. institutional syllabi, annotated with emerald (aligned) and rose (gap) tags.
- **Internship Milestone Tracker:** Stepper component with crisp completed states (`#10B981`), in-progress pulses (`#4F46E5`), and pending milestones (`#CBD5E1`), connected by 2px solid track lines.
